# Mac 앱 테스트 자동화 — 공유용 가이드북

> 이 폴더 전체를 복사해 사용하세요. 아이폰·안드로이드 앱을 Mac에서 AI와 함께 점검하는 설치·실행 문서만 모았습니다.
> 정리·출처 확인: 2026-10-04. 개인 계정·기기 이력, 조사 보고서·캡처는 포함하지 않습니다.

## 1. 내 기기에 맞는 경로 선택

| 대상 | 진행 순서 | AI가 조작하는 대상 |
| --- | --- | --- |
| 안드로이드 | [연결·scrcpy](안드로이드-맥-미러링-가이드.md) → [ADB 앱 테스트](안드로이드-앱-테스트-자동화-가이드.md) | 폰에 ADB 명령 전달 |
| 아이폰 + ChatGPT/Codex | [Computer Use 활성화](computer-use-guide.md) → [iPhone 미러링 테스트](아이폰-미러링-테스트-자동화-방법론.md) | Mac의 미러링 창 |
| 아이폰 + Claude Code | [공식 런타임 활성화](computer-use-guide.md) → [브리지 플러그인 설치](claude-code-computer-use-guide.md) → [미러링 테스트](아이폰-미러링-테스트-자동화-방법론.md) | 브리지로 Mac의 미러링 창 |

안드로이드 ADB 경로는 Computer Use 설치가 필수는 아닙니다. 명령을 실행하고 생성된 이미지를 읽을 수 있는 Claude Code·Codex 같은 환경이 필요합니다. 아이폰 경로는 Apple의 미러링 연결 조건과 실제 Computer Use 도구가 필요합니다.

## 2. 시작 전 준비

- 테스트할 Mac·폰, 사용할 AI 호스트와 대상 앱.
- Android: 데이터 USB 케이블·USB 디버깅 승인.
- iPhone: 지원 Mac·iOS, 같은 Apple 계정·이중 인증·Wi-Fi·Bluetooth.
- 테스트 전용 계정과 앱의 초기 상태.
- 한 가지 시나리오, 입력값, 기대 결과, 중단 지점.

설치·디버깅·시스템 권한의 인증은 사용자 조작이 필요할 수 있습니다. 가이드의 CLI는 설정 화면을 열 수 있지만 권한 자체를 자동으로 허용하지 않습니다.

## 3. 다른 PC의 Claude·Codex에 전달할 요청

이 폴더의 위치와 함께 아래 요청을 전달하세요. 대괄호 부분을 실제 테스트 조건으로 바꾸세요.

```text
이 폴더의 README와 내 기기에 해당하는 가이드부터 읽고 앱 테스트를 진행해줘.
대상: [Android 또는 iPhone], [AI 호스트], [테스트 앱]
시나리오: [초기 상태 → 입력값 → 조작 → 기대 결과]
중단 지점: [예: 결제·메시지 발송 전]

1. 현재 OS·설치 도구·연결 상태부터 확인해.
2. 필요한 설치와 연결을 문서의 명령으로 진행하고 실제 성공 신호를 확인해.
3. 인증·폰 승인·시스템 권한이 필요하면 정확한 앱·설정 경로를 안내하고 기다려.
4. Android는 대상 시리얼을 로컬에서 선택하고 원본 화면 픽셀 기준으로 ADB를 사용해.
5. iPhone은 Computer Use 계산기 검증과 미러링 연결부터 확인해.
6. 화면 읽기 → 한 번 조작 → 새 화면 확인을 반복해.
7. 기대 결과와 실제 결과를 비교해 PASS / FAIL / BLOCKED로 기록해.
8. 공유 증거에는 이름·기기 시리얼·개인 경로·인증정보를 넣지 마.
설치 메시지만으로 실제 테스트 완료라고 보고하지 마.
도구가 없거나 연결이 막히면 최초 오류 원문과 필요한 다음 조작을 알려줘.
```

AI 호스트가 문서의 도구를 실제로 호출할 수 있어야 합니다. 새 세션이 필요한 설치는 새 세션에서 연결을 다시 확인하세요.

## 4. 첫 성공 확인 후 시나리오 실행

| 확인 단계 | 성공 신호 |
| --- | --- |
| 연결 | 현재 폰 화면이 Mac·캡처에서 보임 |
| 첫 조작 | 지정한 앱·버튼이 의도대로 반응 |
| 결과 판정 | 새 화면과 기대 결과가 일치 |
| 기록 | 입력값·초기 상태·환경·증거 경로·판정이 남음 |

[시나리오·결과 기록 템플릿](테스트_시나리오_결과_기록_템플릿.md)을 프로젝트 폴더에 복사하세요. [원칙·레슨런](DECISION_앱-테스트-시행착오.md)으로 시작 전·진행 중·공유 전 점검을 마치세요.

이 문서들은 화면 탐색·흐름 점검용입니다. 안정적인 반복 회귀 테스트에는 별도 단언·초기화·대기 설계와 실행 결과 측정이 필요합니다. 문서를 읽었다는 사실은 해당 Mac에서의 검증 완료가 아닙니다.
