# 앱 테스트 시나리오·결과 기록 템플릿

> 이 파일을 별도 프로젝트 폴더에 복사해 작성한다. 가이드 공유 폴더에는 빈 템플릿만 둔다.
> 실제 사람·기기 식별자는 적지 않고 계정은 “테스트 계정 A”처럼 표시한다.

## 1. 실행 조건

| 항목 | 값 |
| --- | --- |
| 실행 일시·문서 버전 | 미입력 |
| 시나리오 ID | TC-001 |
| 플랫폼·OS | 미입력 |
| AI 호스트·버전 | 미입력 |
| 연결 도구·플러그인 버전 | 미입력 |
| 대상 앱·버전 | 미입력 |
| 계정 유형·로그인·앱 모드 | 미입력 |
| 초기 상태·테스트 데이터 | 미입력 |
| 원본 화면 크기·좌표 기준 | 미입력 |
| 대기 시간 한도 | 미입력 |
| 중단 지점·제외 동작 | 미입력 |

## 2. 시나리오

목적: 미입력

사전 조건: 미입력

입력값: 미입력

| 단계 | 조작 | 기대 결과 | 실제 결과 | 판정 | 증거 상대 경로 |
| --- | --- | --- | --- | --- | --- |
| 1 | 초기 화면 확인 | 대상 앱·모드·로그인 상태 일치 | 미실행 | NOT RUN | 미입력 |
| 2 | 시나리오 동작 입력 | 미입력 | 미실행 | NOT RUN | 미입력 |
| 3 | 결과 재확인 | 미입력 | 미실행 | NOT RUN | 미입력 |

PASS: 기대 결과 일치. FAIL: 기대 결과 불일치. BLOCKED: 연결·권한·환경 문제로 판정 불가. NOT RUN: 미실행. 로딩 한도 초과 시 제품 실패인지 환경 차단인지 근거와 함께 구분한다.

## 3. 결과와 재현

- 전체 판정: NOT RUN
- 확인한 사실:
- 해석·가설:
- 미확인 범위:
- 최초 오류 원문(개인 경로·토큰 제거):
- 성공 직전 변경한 설정:
- 재현 순서:
- 다음 실행을 위한 초기화·복원 방법:
- 다음 행동:

앱 화면 도달·명령 종료 코드만으로 PASS를 선언하지 않는다. 중요한 숫자는 계산식·화면 증거로 재대조한다.

## 4. 증거 공유 전 확인

- [ ] 문서·이미지·XML·로그·파일명에 실제 이름·연락처·시리얼·개인 홈 경로·인증정보 없음
- [ ] 불필요한 개인 주문·운영 데이터 화면 제외
- [ ] 가림 처리한 이미지를 다시 열어 확인
- [ ] 증거가 실제 존재하고 문서에서 상대 경로로 연결됨
- [ ] 결과·증거를 함께 전달하고 가이드 공유 폴더와 분리
