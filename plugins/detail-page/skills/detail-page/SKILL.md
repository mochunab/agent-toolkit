# 상세페이지 작업

고객의 구매 망설임 하나를 정하고 그것을 푸는 순서로 11개 섹션 시안을 만든다. 규칙은 이 스킬의 `references/`에 있고, 아래 절차는 그것을 실제로 읽고 적용하는 순서다.

- `<스킬>`: 이 SKILL.md가 있는 폴더. 이 폴더 안 파일은 고치지 않는다(업데이트 때 덮어써진다).
- `<작업폴더>`: 사용자의 콘텐츠 작업 폴더. 대화에 없으면 묻고, 답이 없으면 현재 폴더를 쓴다.

## 0. 작업 조건 — 처음 한 번 확인

대화에서 알 수 있으면 묻지 않는다. 모르는 값은 기본값으로 진행하고 초안 상단에 적는다.

| 항목 | 기본값 | 영향 |
|---|---|---|
| 판매 채널·이미지 폭 | 스마트스토어 · 가로 860px | 다른 채널은 그 채널 판매자 안내에서 권장 폭을 확인해 `render.py --width <폭>`. 확인 못 했으면 860으로 두고 보고에 적는다 |
| 상품 출처 | 묻는다(자체 제작 / 브랜드 / 위탁·도매 / 수입) | 증거 1단계 자료(사양서·원문)를 누가 주는지, 실물이 있는지 |
| 사진 출처 | 직접 촬영 | 받은 사진이면 사용 허락 확인이 게이트에 추가된다 |
| 상품군 금지어 | `check_copy.py` 기본 목록 | 상품군 표현은 `--extra`로 더한다(식품·화장품·건강 관련은 특히) |

## 1. 시작 전 — 실제로 읽는다 (링크 발견 ≠ 읽음)

1. `references/strategy.md` — 내용·문장·증거 규칙 **(우선)**
2. `references/design-guide.md` — 흐름·모양·제작 절차
3. `references/lessons.md` **1장 원칙만**. 작업폴더에 `상세페이지/레슨런.md`가 있으면 그것도 읽는다
4. 같은 상품군 리뷰 많은 순 상위 3~5개 상세페이지 **실물**을 끝까지 본다. 참고 없이 만들면 앱 화면 같은 카드형 배치가 나온다
5. 완성 예시: `assets/sample/현관문_시안예시/상세페이지.html` (원래 사진은 자리표시 이미지)

## 2. 게이트 — 통과 전에는 시안을 만들지 않는다

- [ ] 상품 한 개·옵션 한 개의 `상세페이지_초안.md`가 있고 **결정 네 줄**(고객·상황 / 원하는 변화 / 구매 망설임 / 선택할 이유)과 **증거 단계**(1 자료 확인 / 2 실물 확인 / 3 반복 시험·판매 후)가 채워져 있다. 양식은 `assets/template/초안_양식.md`(폴더를 만들면 자동 배치)
- [ ] 받은 이미지(제조사·공급처·브랜드 제공)를 쓰면 사용 허락을 확인했다. 미확인이면 시안은 만들되 게시 전 확인 항목에 적는다
- [ ] 증거 1단계면 효과(단열·소음·흡수 등)·시연·전후 비교·가격·반품 약속 문구를 넣지 않는다
- 새 설득 장치·주장·운영 약속(상담·교환)을 넣을 때마다 전략서 4절(불만 언급)·6절(증거 단계)과 대조한다. 충돌하면 확정 전에 사용자에게 묻는다
- AI로 제품·사용 장면·후기 이미지를 만들지 않는다. 사진이 부족하면 섹션을 줄이거나 촬영 목록에 올린다

## 3. 진행

필요: Python 3.9+ · Playwright(`pip install playwright`) · Pillow(`pip install pillow`) · Google Chrome · 인터넷(글꼴). 확인: `python3 -c "import playwright, PIL"` 오류 없음. 렌더는 설치된 Chrome을 쓰므로 `playwright install`은 필요 없다.

폴더 만들기 — 템플릿 복사, `원본이미지/`·`이미지/` 생성, `상세페이지_초안.md` 양식 배치, 작업폴더에 `상세페이지/결정기록.md`가 없으면 양식으로 만든다. 상품 폴더가 이미 있으면 덮어쓰지 않고 멈춘다.

```bash
python3 "<스킬>/scripts/new_product.py" detail "<상품명>" --root "<작업폴더>"
D="<작업폴더>/상세페이지/상품별초안/<상품명>/상세페이지_디자인"
```

작업폴더에 `상세페이지/디자인_템플릿/`(직접 고친 템플릿)이 있으면 스킬 템플릿보다 먼저 쓴다.

| 단계 | 명령·할 일 |
|---|---|
| 사진 나누기·좌표 | `python3 "$D/도구/image_tools.py" split "$D/원본이미지/원본.jpg"` · `grid <조각> --y0 <시작y>` |
| 자르기·확인 | `… crop <원본> x1 y1 x2 y2 <저장>` · `… sheet <저장> <사진들>` · `… upscale <사진>` |
| 문구·사진 넣기 | `상세페이지.html`의 `[대괄호]`·`ph-box` 교체, 안 쓰는 섹션은 `<section>`째 삭제 |
| PNG 뽑기 | `python3 "$D/render.py"` (채널 폭이 다르면 `--width <폭>`) → `출력/` 섹션별 PNG. **PNG를 전부 눈으로 확인** |
| 문구 검사 | `python3 "$D/도구/check_copy.py" "$D/상세페이지.html" --extra <상품군 금지어>` — 효과 표현 0건. 근거 자료가 있는 단어만 `--allow`. 등록 직전엔 대괄호 0·확인 필요 0 |
| 숫자 대조 | 페이지의 모든 숫자를 근거 파일과 하나씩 대조. 애매하면 보수적으로 줄이고 각주에 기준 공개 |
| 글자 정보 | 핵심 치수·옵션표·제한·고시 정보를 이미지 밖 글자·표로도 정리(채널 편집기에 넣을 것) |

디자인 검수는 `references/design-guide.md` 7장 체크리스트로 한다. 크게 바꾸기 전 시안은 `이전버전/vN/`으로 옮긴 뒤 수정한다.

## 4. 함정

- 경로에 공백·한글이 있을 수 있다 → 항상 따옴표, `cd … &&`로 잇지 말고 절대경로로 실행(동기화 폴더에서 출력 없이 실패한 적 있음)
- 글꼴을 CDN에서 받으므로 PNG 뽑을 때 인터넷이 필요하다. 오프라인이면 글꼴이 바뀐 채로 렌더된다
- 템플릿을 고치고 싶으면 `assets/template/`을 `<작업폴더>/상세페이지/디자인_템플릿/`으로 복사해 거기서 고친다
- 일부 한글 파일명·문서는 자모가 분리된(NFD) 상태일 수 있다(macOS·동기화 폴더). 문자열을 비교·치환하기 전에 완성형(NFC)으로 맞춘다
- `check_copy.py` 통과는 광고 심의·표시 의무 준수를 뜻하지 않는다. 식품·화장품·의료기기·건강기능식품 등은 해당 법령·채널 정책을 사람이 따로 확인한다

## 5. 끝내기 전 — 빠뜨리면 미완료

1. `<작업폴더>/상세페이지/결정기록.md`에 이번 작업의 결정·과정·실수 추가
2. 다음 작업에도 적용될 교훈은 `<작업폴더>/상세페이지/레슨런.md`로 승격(없으면 `references/lessons.md`의 표 형식으로 만든다)
3. 새 상품이면 완료 보고에 **미구현분(남은 `확인 필요`·미확인 값·확인 못 한 채널 폭)을 먼저 나열**
4. 핵심/기타 분리 — 초안 md는 핵심, `근거/`·`원본이미지/`·`출력/`은 기타
