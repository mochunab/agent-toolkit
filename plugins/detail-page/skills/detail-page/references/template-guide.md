# 상세페이지 디자인 템플릿

> 위치: 템플릿은 이 스킬의 `assets/template/`에 있고, `scripts/new_product.py detail <상품명> --root <작업폴더>`가 복사·폴더 생성을 대신한다. 작업폴더에 `상세페이지/디자인_템플릿/`을 두면 그것을 먼저 쓴다(직접 고친 템플릿). 완성 예시는 `assets/sample/현관문_시안예시/`(원래 사진은 자리표시 이미지).

> 용도: 새 상품 상세페이지 시안을 만들 때 복사해서 쓰는 공통 틀. 11개 섹션 뼈대·공통 스타일·PNG 뽑기·사진 도구·문구 검사가 들어 있음.
> 독자: 상세페이지를 만드는 작업자, 같은 작업을 맡는 AI.
> 자매 문서: [디자인 가이드](design-guide.md)(흐름·모양 규칙) · [작성 전략서](strategy.md)(내용·증거 기준) · [완성 예시: 현관문 시안 v2](../assets/sample/현관문_시안예시/상세페이지.html).
> 원칙: 이 폴더는 직접 고치지 않고 **복사해서** 씀. 템플릿을 고치면 이미 만든 상품 시안은 바뀌지 않음.

## 1. 무엇이 들어 있나

| 파일 | 역할 | 고치는 경우 |
|---|---|---|
| `상세페이지.html` | 11개 섹션 뼈대. `[대괄호]`는 상품 정보로 바꿀 자리, 파란 점선은 확인 뒤 채울 값 | 상품마다 문구·사진 교체 |
| `style.css` | 색·글꼴·구성 요소 모양 | 강조색을 바꿀 때 맨 위 색 값만 |
| `render.py` | 섹션마다 PNG(기본 가로 860px, `--width`로 변경) + 전체 미리보기를 `출력/`에 저장 | 고치지 않음 |
| `도구/image_tools.py` | 긴 이미지 나누기·좌표 격자·자르기·확대·모아 보기 | 고치지 않음 |
| `도구/check_copy.py` | 근거 없는 효과 표현·남은 대괄호·확인 필요 표시 검사 | 금지어 추가는 실행할 때 `--extra`로 |

## 2. 새 상품 시작하기

전제: 전략서 기준 초안(md)이 있고, 받은 이미지를 쓰면 사용 허락을 확인함. 이 컴퓨터에 Python3·Playwright(파이썬)·Pillow·Google Chrome이 있음(`python3 -c "import playwright, PIL"` 오류 없음).

경로에 띄어쓰기가 있을 수 있으므로 모든 경로를 따옴표로 감쌈. 아래 `<스킬>`은 이 스킬 폴더, `<작업폴더>`는 콘텐츠 작업 폴더, `<D>`는 만들어진 `상세페이지_디자인` 폴더의 절대경로.

| 단계 | 할 일 | 성공 신호 |
|---|---|---|
| 1. 복사 | 아래 명령으로 템플릿을 상품 폴더에 복사하고 사진 폴더·초안 양식을 만듦 | `상품별초안/<상품명>/상세페이지_디자인/` 안에 파일 3개 + `도구/` + 사진 폴더 2개, 상품 폴더에 `상세페이지_초안.md` |
| 2. 원본 사진 | 직접 찍은 원본 또는 사용을 허락받은 상세 이미지 원본을 `원본이미지/`에 저장 | 원본 해상도 확인(썸네일보다 상세 원본이 큰 경우가 많음) |
| 3. 나눠 보기 | `split`으로 조각을 만들어 쓸 사진·뺄 문구 띠를 고름 | 조각 파일명에 시작 y좌표가 있음(`조각_y01900.jpg`) |
| 4. 자르기 | 조각 좌표 + 파일명의 y좌표 = 원본 좌표로 `crop`. 끝나면 `sheet`로 모아 확인 | 모아 본 사진에 글씨·효과 문구 띠가 섞이지 않음 |
| 5. 문구·사진 넣기 | `상세페이지.html`의 `[대괄호]`를 초안 내용으로, `ph-box`를 `<img>`로 바꿈. 안 쓰는 섹션은 `<section>`째 지움 | 브라우저로 열었을 때 깨진 사진 없음 |
| 6. PNG 뽑기 | `render.py`를 절대경로로 실행 | 섹션마다 `가로 x 높이`(기본 가로 860) 출력, `출력/`에 PNG |
| 7. 검사 | `check_copy.py` 실행 후 [디자인 가이드 7장](design-guide.md#7-다-됐는지-확인--디자인-검수) 체크리스트 | 효과 표현 0건. 등록 직전엔 대괄호 0종·확인 필요 0개 |

```bash
# 1. 복사 — 템플릿 + 원본이미지/·이미지/ + 상세페이지_초안.md 양식 + (없으면) 상세페이지/결정기록.md
python3 "<스킬>/scripts/new_product.py" detail "<상품명>" --root "<작업폴더>"
# 만들어진 곳: <작업폴더>/상세페이지/상품별초안/<상품명>/상세페이지_디자인  (= <D>)

# 6. PNG 뽑기 — cd 하지 말고 절대경로로. 채널 권장 폭이 다르면 --width
python3 "<D>/render.py"
python3 "<D>/render.py" --width <채널 권장 폭>

# 7. 문구 검사 — 상품군 금지어는 --extra, 근거 자료가 있는 단어만 --allow
python3 "<D>/도구/check_copy.py" "<D>/상세페이지.html" --extra 단어,단어
```

## 3. 사진 도구

`<D>`는 상품의 `상세페이지_디자인` 폴더 절대경로.

```bash
python3 "<D>/도구/image_tools.py" split "<D>/원본이미지/원본.jpg"                 # 950px 조각 → 원본이미지/원본_조각/
python3 "<D>/도구/image_tools.py" grid "<D>/원본이미지/원본_조각/조각_y02850.jpg" --y0 2850   # 원본 기준 좌표 격자
python3 "<D>/도구/image_tools.py" crop "<D>/원본이미지/원본.jpg" 271 3260 527 3630 "<D>/이미지/설치2.jpg"   # 왼쪽 위 오른쪽 아래
python3 "<D>/도구/image_tools.py" upscale "<D>/이미지/설치2.jpg"                  # 설치2@2x.jpg (2배 + 선명화)
python3 "<D>/도구/image_tools.py" sheet "<D>/이미지/_확인.jpg" "<D>/이미지/"*.jpg   # 잘라 낸 사진 모아 보기
```

- 사진 위 주석(빨간 점선 원)을 넣을 때는 넣을 사진에 `grid`를 그려 좌표를 읽고, HTML의 `svg viewBox`를 사진 크기와 같게 맞춤.
- 작은 사진은 `upscale`로 키워도 화면에는 원본 폭의 약 1.7배까지만 크게 씀.

## 4. 자주 하는 수정

| 하고 싶은 것 | 방법 |
|---|---|
| 강조색 바꾸기 | `style.css` 맨 위 `--yellow`(강조)·`--red`(주석·경고) 값만 바꿈. 한 페이지에 강조색 1개 + 주석색 1개 |
| 확인 섹션 수 조절 | `s04-확인1`~`s06-확인3` 중 필요한 만큼 복사·삭제. 3번 섹션의 확인 목록 개수도 같이 맞춤 |
| 재구매(D 유형)처럼 짧게 | 2 자가진단·3 반전 섹션을 지우고 첫 화면에 제품명·규격·수량 |
| 안심 장치를 운영하지 않음 | `s08-안심` 섹션을 지움(운영 약속은 정한 뒤에만 게시) |
| 배경 순서 | 같은 배경이 연달아 오지 않게 `bg-panel`·`bg-dark` 교대, `bg-yellow`는 한 곳 |
| 다른 채널 폭으로 저장 | `render.py --width <폭>`. 레이아웃은 860px 기준 그대로, 이미지 크기만 비율대로 바뀜 |
| 내 템플릿 만들기 | `assets/template/`을 `<작업폴더>/상세페이지/디자인_템플릿/`으로 복사해 고침. 이후 `new_product.py`가 그것을 씀 |

## 5. 주의

- 핵심 치수·옵션표·제한·고시 정보는 이미지 밖 판매 채널 편집기에 글자·표로도 넣음([전략서 3절](strategy.md#3-첫-화면과-각-구간은-어떻게-작성할까)).
- 3번 반전 섹션의 후기 수치는 [전략서 4절 예외](strategy.md#4-같은-상품군의-고객-불만은-어떻게-쓸까)·[6절](strategy.md#6-어떤-주장에-어떤-증거가-필요한가) 기준(선택 실패 불만만, 분류 기준 공개, 해결 주장 금지)을 지킬 때만 씀.
- 글꼴은 인터넷에서 불러오므로 PNG를 뽑을 때 인터넷 연결이 필요함.
- 배송·반품 표의 “상품 정보와 다를 때” 문구는 전자상거래법 청약철회 기준을 쉬운 말로 옮긴 것. 판매 채널 설정과 다르면 맞춰 고침.
