# 현관문 고무패킹 6.3M — 30초 홍보 영상 (검수용 시안)

> 용도: 상세페이지 v2의 흐름·문구·사진으로 만든 30초 모션 그래픽 영상의 구성표와 문구 근거 **예시**. 공급처 사진 때문에 영상 파일은 싣지 않았다. 공급처·가격 등 사업 정보와 일부 근거 링크는 공개본에서 뺐다.
> 독자: 영상을 확인하고 게시 여부를 정할 작업자, 같은 작업을 맡는 AI.
> 상태: **예시 문서(2026-10 작성).** 아래 숫자·후기 수치는 작성 시점의 조사값이며 다른 상품에 그대로 쓰지 않는다.
> 만드는 법·원칙: [제작 가이드](../../references/video-guide.md) · [레슨런](../../references/lessons.md) · [결정 기록](../../references/decision-log-template.md)
> 증거 단계: 1(공급처 자료) — [전략서 6절](../../../detail-page/references/strategy.md#6-어떤-주장에-어떤-증거가-필요한가) 기준. 효과·시연·비교 문구 없음.

| 항목 | 내용 |

| 소스 | 소스/ — `영상.html`(화면) · `audio.py`(소리) · `timing.py`(시간표) · `render.py`(렌더) |

## 2. 장면 구성 (0.5초 격자, 120BPM)

| 시간 | 장면 | 화면 | 화면 문구 | 근거 |
|---|---|---|---|---|
| 0~3.5초 | 첫 화면 | 감긴 패킹 사진 + 스펙 띠 | 현관문 패킹, 직접 갈아 끼우세요 / 6.3m · 2.1m × 3줄 · 18 × 14mm / 문틀에 홈이 있는 현관문 전용 | 공급처 원문 2절 1·6·7번 |
| 3.5~7초 | 자가진단 | 체크리스트 4개 + 오래된 패킹 사진(빨간 점선 주석) | 딱딱하게 굳었어요 · 갈라지고 부스러져요 · 홈에서 들뜨거나 빠져나와요 · 납작 눌려서 안 돌아와요 / 하나라도 해당되면, 패킹을 갈 때가 된 거예요 | 고객 쪽 상태만. 제품 성능 주장 아님 |
| 7~14초 | 반전 | 후기 말풍선 4개 → 32/58건 → 출처 각주 → 한 줄 결론 | 패킹은 ‘우리 문에 맞는지’가 먼저예요 | 초안 S03 · 전략서 4절 예외(선택 실패) |
| 14~17.5초 | CHECK 01 | 설치 사진 + O/X 두 칸 | 문틀에 ‘홈’이 있나요? / 홈이 없으면 설치할 수 없어요 | 공급처 원문 2절 1·9번 |
| 17.5~21초 | CHECK 02 | 단면 사진(18mm·14mm 표시) + 스티커 | 18mm, 우리 문 틈에 맞을까요? / 자르기 전에, 한 줄 먼저! | 공급처 원문 2절 7번(오차 문구 병기) · 재단 후 반품 불가 진술 2건 |
| 21~24.5초 | CHECK 03 | 문 배치 그림이 한 줄씩 그려짐 + 계산 띠 | 2.1m × 3줄이면 현관문 하나 끝 / 세로 × 2 + 가로 ≤ 6.3m / 가로 1,100 × 세로 2,100mm | 공급처 원문 2절 5·6번 |
| 24.5~27.5초 | 설치 | 사진 3장이 차례로 눌려 들어옴 | 꾹! 꾹! 눌러 끼우면 끝 / 기존 패킹을 빼요 · 빈 홈에 새 패킹을 꾹꾹 눌러 끼워요 · 문을 여닫아 밀착을 확인해요 | 공급처 원문 2절 8번(사용 방법 안내로만 사용) |
| 27.5~30초 | 마무리 | 노랑 배경 + 스펙 띠 + 3칸 | 문틀에 홈이 있는 현관문 전용이에요 / 주문 전에, 이 3가지만 확인하세요: 홈 · 두께 · 길이 | 위와 같음 |

## 3. 어떻게 만들었나 (설계 판단)

| 판단 | 이유 |
|---|---|
| 상세페이지 v2의 흐름·색·서체·구성 요소를 그대로 가져옴 | 이미 “AI 같다”를 벗어난 시안이라 같은 모양을 유지. 노랑·빨강·검정, 굵은 선 표, 형광펜, 스티커, 사진 위 주석 |
| 반전(실패 통계) 바로 뒤에 해결(“주문 전 3가지”)을 이음 | 레슨런 1장: 실패 통계는 불안도 키우므로 바로 “이렇게 확인하면 돼요”로 이어야 함 |
| 출처 각주를 약 3초 화면에 유지 | 통계는 출처·분류 기준을 읽을 수 있어야 함(전략서 6절) |
| 안심 장치(사진 상담)와 FAQ·배송·반품 정보는 영상에서 뺌 | 운영 약속 미결정, 반품·재단 후 처리 미확인 |
| 사진은 작게·원본 폭 안에서 | 설치 사진 원본이 256px. 512px로 키운 사진을 540px 이하로만 사용 |
| 화면 아래 파란 띠 | 상세페이지 v2의 검수 띠와 같은 약속. 게시용 렌더는 `render.py video … --clean` |

## 4. 게시 전 확인할 것

| 항목 | 상태 | 다음 행동 |
|---|---|---|
| 공급처 이미지 영상 가공 허용 | **미확인.** 원문은 “상세설명 이미지 사용허용”, 편집·합성 허용 범위는 미확인(공급처 원문 1절) | 공급사에 영상 제작·게시 허용을 확인한 뒤 게시 |
| 판매 확정 | 후보용 상품은 게시하지 않음. 공급가·옵션 미확인 | 판매 확정 전에는 게시하지 않음 |
| 32/58건 | 원문 대조 없이 브라우저 에이전트 요약 기준(초안 S03) | 큰 숫자라 원문 대조 후 게시 권장 |
| 18×14mm | 공급처 원문에 “측정 방법·위치에 따라 차이” 문구 | 확인 장면(CHECK 02)에 병기. 첫 화면 스펙 띠에는 병기 안 함(v2와 동일) |
| 네이버 상품 동영상 규격 | 이 문서 작성자가 확인하지 못함 | 등록 전 스마트스토어 안내에서 비율·용량·길이 확인 |

## 5. 공유 문구 (올릴 때 그대로)

> 현관문 패킹, 직접 갈아 끼우세요. 주문 전에 홈·두께·길이 3가지만 확인하면 돼요. (문틀에 홈이 있는 현관문 전용)

## 6. 다시 만들기

| 하고 싶은 일 | 방법 |
|---|---|
| 검수 띠 없는 게시용 렌더 | ① `python3 "<소스>/audio.py" "<임시>/audio_raw.wav"` ② `ffmpeg -y -i "<임시>/audio_raw.wav" -af "loudnorm=I=-16:TP=-1.5:LRA=11" -ar 44100 "<임시>/audio.wav"` ③ `python3 "<소스>/render.py" video "<임시>/게시용.mp4" --audio "<임시>/audio.wav" --clean` (소리는 시드 고정이라 지금 영상과 같음. `audio.wav`는 소스 폴더에 저장돼 있지 않음) |
| 가로(16:9)·정사각 | 별도 작업. 화면 배치를 다시 짜야 함 |
| 문구·장면 길이 수정 | `영상.html`(문구·배치), `timing.py`(장면 시간·효과음 시점). 렌더·음악은 같은 시간표를 읽음 |
| 필요한 것 | Python3 + Playwright + Chrome, ffmpeg. `cd` 하지 말고 절대경로로 실행 |
