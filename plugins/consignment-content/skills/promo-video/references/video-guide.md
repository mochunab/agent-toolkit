# 상품 홍보 영상 제작 가이드

> 용도: 상세페이지가 끝난 상품으로 **30초 모션 그래픽 홍보 영상**을 만들 때의 흐름·문구 규칙·장면 설계·소리·제작 절차·검수. 새 상품 영상을 만들 때마다 이 문서로 시작함.
> 독자: 영상을 확인하고 게시를 정할 작업자, 같은 작업을 맡는 AI(Claude·Codex).
> 기준 결과물: 현관문 고무패킹 30초 영상. 공급처 사진 때문에 mp4는 싣지 않았다. 구성표·문구 근거는 [계획 예시](../assets/sample/현관문_영상계획예시.md), 소스는 `assets/template/`(사진은 자리표시 이미지).
> 자매 문서: [레슨런](lessons.md)(원칙·교훈, 시작 전 1장 확인) · [결정 기록](decision-log-template.md)(작업별 결정·실수) · [인계서](handoff-template.md)(현재 상태·다음 영상 시작 양식) · [영상 템플릿](template-guide.md)(복사해서 시작).
> 우선순위: **내용·문장·증거 규칙은 [상세페이지 전략서](../../detail-page/references/strategy.md)가 우선.** 이 문서는 그 내용을 영상으로 어떻게 보여 줄지만 정함.

## 1. 한눈에 보기

**상세페이지 v2가 영상의 대본이다. 새로 쓰지 말고, 같은 흐름을 30초로 압축한다. 증거 1단계의 문구 규칙은 영상에서도 그대로 지킨다.**

| 정할 것 | 기본값 | 자세히 |
|---|---|---|
| 규격 | 세로 9:16 · 1080×1920 · 30fps · 30초 · 소리 있음 | 4장 |
| 흐름 | 첫 화면 → 자가진단 → 반전(실패 데이터) → 확인 3개 → 사용법 → 마무리, 8장면 | 3장 |
| 문구 | 상세페이지 v2 문구를 줄여 씀. 새 주장·숫자 금지 | 2장 |
| 모양 | v2의 색·서체·형광펜·스티커·사진 위 주석을 영상 크기로 다시 배치 | 4장 |
| 소리 | 음악·효과음을 직접 합성(외부 음원 없음). 전환음은 아주 작게 | 5장 |
| 만드는 법 | 화면을 HTML로 짜고 시간의 함수로 프레임을 찍어 mp4로 인코딩 | 6장 |
| 게시 | 검수 띠가 있는 시안으로 승인받은 뒤 `--clean`으로 다시 렌더 | 8장 |

그래서: 상세페이지가 없거나 증거 단계가 안 정해진 상품은 영상부터 만들지 않는다. 상세페이지 → 영상 순서. (작성자가 세운 기본 원칙이며 사용자가 명시한 규칙은 아님. 사용자가 다르게 정하면 따른다.)

## 2. 무엇을 말할까 — 문구 규칙

### 시작 전에 읽을 것 (실제로 읽고 적용)

1. 작업 폴더의 작업 규칙 문서(있으면)
2. 이 가이드 → [레슨런 1장 원칙](lessons.md#1-원칙--영상이-밋밋하거나-거슬리기-전에-이것부터) → [인계서](handoff-template.md)
3. [상세페이지 전략서](../../detail-page/references/strategy.md) 3절(문장)·4절(불만 언급 예외)·6절(증거 단계), [디자인 가이드](../../detail-page/references/design-guide.md) 3·4·5장
4. 그 상품의 `상세페이지_초안.md`·완성된 `상세페이지.html`·`근거/공급처_원문_*.md`

### 증거 1단계(공급처 자료)에서 쓸 수 있는 것·없는 것

| 쓸 수 있음 | 쓰지 않음 |
|---|---|
| 공급처 원문의 규격·구성·소재·설치 방식·적용 크기 | 외풍·단열·소음·냄새 등 효과 문구와 수치 |
| 설치 순서(**사용 방법 안내**로만, 성능 증명 아님) | 시연·전후 비교·성능 장면 |
| 고객 쪽 상태 체크리스트(제품 성능 아님) | 난연·인증·시험 결과(자료 없으면) |
| 선택 실패 후기 수치 — 출처 각주 + 분류 기준 공개, 구매 전 확인 안내의 근거로만 | 가격·무료배송·최저가, 반품·교환 약속 |
| 실패를 막는 규칙 스티커(실제 불만에서 나온 것만) | 운영 미결정 약속(사진 상담 등) |
| 후기를 줄인 말풍선(“줄인 문장” 안내 필수) | 경쟁사 이름·후기 캡처, 생성한 후기·AI가 그린 제품 |

- 문구는 상세페이지 `확인 필요`(파란 점선) 표시가 붙은 값을 쓰지 않는다. 영상에 파란 점선은 없어야 한다.
- 제목은 짧은 구어체(“꾹! 꾹! 눌러 끼우면 끝”)를 쓸 수 있고, 설명 문장은 `~해요`로 통일.
- 숫자는 근거 파일 위치를 댈 수 있는 것만. 영상에 쓴 숫자는 [계획](../assets/sample/현관문_영상계획예시.md)처럼 장면별 근거 표로 남긴다.
- 영상은 소리·움직임이 있어 한 번 지나가면 되돌려 읽기 어렵다. 그래서 **글자 수가 상세페이지보다 훨씬 적어야 한다**(3장 읽는 시간 기준).

## 3. 장면은 어떻게 짜나

### 기본 뼈대 (30초 = 8장면, 0.5초 격자)

현관문 영상 기준. 확인 섹션 수는 상품의 구매 망설임 개수(1~4)에 맞춰 늘리고 줄이되 **전체는 30초**를 지킨다.

| 시간 | 장면 | 고객 머릿속 질문 | 들어갈 것 | 배경 |
|---|---|---|---|---|
| 0~3.5초 | A 첫 화면 | 이게 뭐고 나한테 뭐가 좋아? | 원하는 동작 한 문장 + 제품 사진 + 스펙 띠 + 핵심 조건 한 줄 | 흰색 |
| 3.5~7초 | B 자가진단 | 우리 집 얘기인가? | 체크 4개 + 상태 사진 + 결론 한 줄 | 연회색 |
| 7~14초 | C 반전 | 그냥 사면 되나? | 후기 말풍선 → 큰 숫자 → 출처 각주 → 한 줄 결론 | 어두운색 |
| 14~24.5초 | D1~D3 확인 | 우리 환경에 맞나? | 장면당 질문 하나(3.5초씩): 배지 + 제목 + 증거 사진·그림 + 한 줄 | 흰·연회·흰 |
| 24.5~27.5초 | E 사용법 | 나도 할 수 있나? | 구어체 제목 + 단계 사진 3장 | 어두운색 |
| 27.5~30초 | F 마무리 | 결국 뭘 확인하지? | 핵심 조건 + 스펙 띠 + “주문 전 확인 N가지” | 노랑 |

- 배경은 같은 색을 연달아 두지 않는다. 노랑은 마무리 1곳(v2의 안심 섹션 자리를 영상에서는 마무리가 씀).
- **반전(C) 바로 뒤에 해결(D)을 붙인다.** 실패 통계는 불안도 키우므로 곧바로 “이렇게 확인하면 돼요”로 잇는다.
- 장면 하나 = 초점 하나. 큰 제목 + 형광펜 한 곳, 또는 큰 숫자, 또는 스티커.

### 읽는 시간 (가장 많이 실패하는 곳)

- 시청자가 읽어야 하는 문장은 **완전히 자리 잡은 뒤 단어당 약 0.3초** 화면에 둔다(외부 영상 스킬의 가독성 기준을 가져온 값이며 실측 규칙은 아님). 여러 줄이 순서대로 나타나면 읽기가 겹치므로 마지막 줄 기준으로 센다.
- 한 장면 3.5초 = 제목 3~4단어 + 사진/그림 + 한 줄이 한계. 넘치면 문장을 줄이지 말고 **장면 수를 줄인다**(예: 안심 장치·FAQ·정보 표는 영상에서 뺌).
- 출처 각주는 작아도 **약 3초** 유지. 못 둘 만큼 자리가 없으면 숫자를 빼고 말풍선만 남긴다.
- 첫 2초가 승부. 0.25초에 첫 제목 줄이 꽂히고 1초 안에 사진이 올라온다.

### 움직임 레시피 (현관문 영상에서 쓴 것)

| 요소 | 움직임 | 길이 |
|---|---|---|
| 제목 줄 | 아래에서 60~70px 올라오며 나타남(줄마다 0.3초 간격) | 0.35초 |
| 형광펜 | 왼쪽에서 오른쪽으로 닦음(어두운 배경은 노란 상자 전체를 닦음) | 0.4~0.45초 |
| 사진 | 옆·아래에서 밀려 들어옴 | 0.4~0.5초 |
| 사진 위 주석 | 점선 원이 0.6→1로 튀며 나타남 → 지시선 → 빨간 라벨 | 0.3초 |
| 체크 표시 | 줄이 왼쪽에서 들어오고 체크가 그려짐 | 0.25 + 0.2초 |
| 말풍선 | 0.6→1로 튕기며 좌우 번갈아(0.4초 간격) | 0.3초 |
| 큰 숫자 | 0에서 목표값까지 세어 올림 + 끝에서 낮은 “쿵” | 0.7초 |
| 스티커 | 1.7→1로 쾅 떨어짐(기울기 -2.5도 유지) | 0.3초 |
| 단계 사진 | 아래에서 올라온 뒤 “꾹” 한 번 눌린 듯 1.035배 | 0.3 + 0.45초 |
| 도식 | 선·막대가 한 줄씩 그려지며 번호 원이 튐 | 0.3초 |
| 장면 전환 | 다음 장면이 **아래에서 위로 닦으며** 덮음 | 0.3초 |

- 전환은 크로스페이드를 쓰지 않는다(복잡한 두 화면이 겹쳐 탁해 보임).
- 장면이 끝나기 전에 요소가 먼저 사라지게 하지 않는다. 다음 장면이 덮을 때까지 그대로 둔다. 같은 자리에서 내용이 바뀔 때만 앞 요소를 걷는다(C의 말풍선 → 큰 숫자).

## 4. 어떤 모양으로 만드나

### 4-1. 크기 — 영상은 폭 1080, 폰에서는 약 0.36배

상세페이지(860px)의 약 1.26배로 키우고, 폰에서 읽히게 더 키운다.

| 역할 | 글꼴 | 영상 크기(1080px 기준) | 폰에서 |
|---|---|---|---|
| 첫 화면 제목 | G마켓 산스 Bold | 104~118px | 약 40px |
| 장면 제목 | G마켓 산스 Bold | 84~92px | 약 31px |
| 큰 숫자 | G마켓 산스 Bold | 250px | 약 90px |
| 결론·스티커 | G마켓 산스 Bold | 64~80px | 약 25px |
| 설명 문장 | 프리텐다드 | 42~58px | 약 16~21px |
| 목록·도식 설명 | 프리텐다드 | 32~46px | 약 12~17px |
| 출처·사진 안내·각주 | 프리텐다드 | **26px 이상** | 약 9.5px |
| 검수 띠 | 프리텐다드 | 27px(검수용에만) | |

- 색은 v2와 같다: 먹색 `#141414`, 노랑 `#FFE04A`, 빨강 `#EB3B26`, 바탕 흰·`#F2F1ED`·`#171717`. 파랑 `#1D6FE8`은 **검수 띠에만**.
- 숫자와 단위가 줄바꿈으로 갈리지 않게 한다. 한 줄에 안 들어가면 글자 크기를 줄인다(예: 스펙 띠 58px).
- 아래 약 64px는 검수 띠 자리. 올릴 앱(릴스·쇼츠·클립 등)이 위·아래를 UI로 가리는 범위는 현관문 영상 때 확인하지 못했다. 게시처를 정하면 그 앱의 안전 영역을 확인한다.

### 4-2. 사진 — 작은 원본을 크게 늘리지 않는다

| 원본 | 영상에서 쓰는 크기 | 이유 |
|---|---|---|
| 800px(제품·단면) | 폭 1080까지(약 1.35배) | 이 이상은 흐려짐 |
| 256px 설치 사진(`@2x`로 512) | 폭 540 이하 | 전체 화면으로 늘리면 흐릿함 |
| 3장 나란히(단계 사진) | 칸당 약 317px | 선명 |

- 사진은 상세페이지 `이미지/`의 잘라 낸 사진을 그대로 쓴다. 공급처 사진 속 효과 문구 띠·시연 장면은 쓰지 않는다.
- 사진마다 “공급처 제공” 표시(26px 이상). AI로 그린 제품·장면 금지.

## 5. 소리는 어떻게 만드나

외부 음원은 쓰지 않는다(상업 영상 저작권 위험). `audio.py`가 numpy로 합성한다.

| 구간 | 음악 구성 | 의도 |
|---|---|---|
| 0~7초(A·B) | 첫 코드 스탭 → 킥·하이햇·플럭 아르페지오·베이스 가볍게 | 훅, 경쾌 |
| 7~14초(C) | 킥을 마디당 1번으로 줄이고 낮은 베이스 지속, 플럭·박수 제거 | 긴장 |
| 14초(D1 시작) | 라이저 → 낮은 임팩트 → 풀 그루브 복귀(박수 포함) | 드롭 |
| 24.5~27.5초(E) | 그루브 + 반짝이는 멜로디 | 고조 |
| 27.5~30초(F) | C메이저 스탭 + 크래시 + 잔향, 끝 0.5초 페이드아웃 | 마무리 |

- 난수 시드가 고정돼 있어 `audio.py`를 다시 돌려도 같은 소리가 나온다. 120BPM, A마이너 펜타토닉. 효과음도 같은 조(A·C·E·G)로 맞춰 음악 아래에 깐다.
- 효과음: 말풍선 팝(음계 음) · 체크 틱 · 숫자 올라가는 틱 · 스티커 쾅 · 꾹 · 막대 그려지는 소리 · 마무리 라벨 팝.
- **전환음은 거의 안 들리게.** 첫 버전의 “솩”이 사용자에게 “너무 크고 거슬린다”는 지적을 받았다. 현재 값: 바람 소리 0.3초·높은 음 제거·gain 0.10, 뒤따르는 “쿵” gain 0.28. 새 영상에서도 이 값에서 시작하고 더 키우지 않는다.
- 전체 소리는 `loudnorm=I=-16:TP=-1.5`로 맞춘다. 현관문 영상 결과 -15.6 LUFS, 피크 -1.2 dBFS.
- **AI는 소리를 직접 들을 수 없다.** 레벨 측정과 장면별 RMS로만 검증하므로, 시안을 줄 때 “소리는 직접 들어 확인해 달라”고 반드시 말하고 거슬리는 소리를 지적받는다.

## 6. 어떻게 만드나 — HTML에서 mp4까지

### 시작 전 확인

- [ ] 상세페이지 시안(v2 수준)과 증거 단계가 있음
- [ ] Python3, Playwright, Google Chrome, ffmpeg, numpy가 있음. 확인: `python3 -c "import playwright, numpy"` · `ffmpeg -version`
- [ ] 쓸 사진이 상세페이지 `이미지/`에 있음
- [ ] 공급처 이미지를 **영상으로 가공**해도 되는지 확인했거나, 게시 전 확인 항목으로 적어 둠
- [ ] 인터넷 연결(글꼴을 CDN에서 받음)

### 절차

| 단계 | 할 일 | 성공 신호 | 막히면 |
|---|---|---|---|
| 1. 틀 복사 | `scripts/new_product.py video <상품명>`이 [영상 템플릿](template-guide.md)을 `상품별/<상품명>/소스/`로 복사하고 남은 이전 상품 흔적 목록을 출력(손으로 복사해도 같음) | `영상.html`·`timing.py`·`render.py`·`audio.py`·`assets/` | — |
| 2. 사진 복사 | 상세페이지 `이미지/`에서 쓸 사진을 `소스/assets/`로 복사하고 템플릿 사진은 지움 | 쓸 사진만 남음 | — |
| 3. 문구·장면표 | 상세페이지에서 장면별 문구를 줄여 고르고 [계획](../assets/sample/현관문_영상계획예시.md) 표처럼 근거와 함께 적음 | 모든 문구에 근거 위치가 있음 | 근거 없으면 문구를 뺌 |
| 4. 시간표 | `timing.py`의 장면 시작·효과음 시점을 0.5초 격자로 정함. 총 30초 | 합이 `END`와 같음 | 읽는 시간이 모자라면 장면 줄이기 |
| 5. 화면 | `영상.html`의 장면·문구·위치를 상품에 맞게 바꿈 | 브라우저에서 깨짐 없음 | 아래 부록 문제표 |
| 6. 정지 화면 검수 | `render.py stills`로 **장면 끝 화면 + 전환 중간 화면**을 뽑아 이어 붙여 전부 봄 | 7장 체크리스트 통과 | 고치고 반복 |
| 7. 문구 검사 | `check_copy.py`를 `--extra`로 상품별 금지어를 더해 실행 | 효과 표현 0건 | 걸린 문구 삭제 |
| 8. 숫자 대조 | 화면의 모든 숫자를 근거 파일과 하나씩 대조 | 숫자마다 근거 위치 | 애매하면 보수적으로 줄임 |
| 9. 소리 | `audio.py`로 합성 → `loudnorm` → 레벨 확인 | 클리핑 0, 전환음 작음 | 5장 값으로 돌아감 |
| 10. 렌더 | `render.py video`로 프레임→mp4, 소리 합치기(약 1분) | 900프레임, AAC, 30초 | 아래 문제표 |
| 11. 확인·기록 | 완성본에서 프레임을 몇 장 뽑아 다시 확인 → 계획·결정 기록·레슨런 갱신 | 7장 + 결정 기록에 항목 | — |

```bash
# 모든 경로는 따옴표로 감싸고 cd 하지 말고 절대경로로 실행. 프레임·임시 파일은 Drive 밖(임시 폴더)에 둠
S="<…/콘텐츠/홍보영상/상품별/<상품명>/소스>"
python3 "$S/render.py" stills 3.4,6.9,13.9 "<임시폴더>/stills"          # 6. 정지 화면
python3 "<이 스킬>/scripts/check_copy.py" "$S/영상.html" --extra 단열,난연,가격,상담
python3 "$S/audio.py" "<임시폴더>/audio_raw.wav"                       # 9. 소리 합성
ffmpeg -y -i "<임시폴더>/audio_raw.wav" -af "loudnorm=I=-16:TP=-1.5:LRA=11" -ar 44100 "<임시폴더>/audio.wav"
python3 "$S/render.py" video "<임시폴더>/영상.mp4" --audio "<임시폴더>/audio.wav"   # 10. 렌더
# 게시용(검수 띠 없음): 위 render 명령 끝에 --clean 추가
```

- **작업 위치:** 소스·완성 mp4·계획 문서만 Drive 폴더에 둔다. 프레임·정지 화면·중간 wav는 임시 폴더. Drive 동기화 부담과 핵심/기타 분리 규칙 때문.
- 화면은 시간의 순수 함수(`renderAt(t)`)라서 같은 시각이면 항상 같은 프레임이 나온다. 브라우저 하나로 순서대로 찍는다(RAM 8GB 기준 약 1분).
- 0번 프레임은 첫 화면이 자리 잡은 순간(3.4초)으로 바꿔 넣는다. 썸네일에 빈 화면이 안 뜸.

## 7. 다 됐는지 확인 — 영상 검수

내용 검수는 [전략서 9절](../../detail-page/references/strategy.md#9-무엇을-확인하면-작성이-끝난-것인가)을 먼저 통과시킨다. 그다음:

- [ ] 첫 화면(0~3.5초)만 보고 무엇을 파는지·누구용인지·핵심 조건을 안다
- [ ] **이전 상품의 문구·사진이 남아 있지 않음**(템플릿은 현관문 내용 그대로다. `영상.html`에서 `현관문`·`패킹`·`6.3`·`2.1m`·`18`·`32`·`58` 등을 검색해 0건 확인)
- [ ] 장면마다 초점이 하나. 장면 길이 안에 읽을 문장이 단어당 0.3초 기준으로 들어감
- [ ] 전환마다 중간 화면이 깨끗함(두 화면이 겹쳐 탁하지 않음)
- [ ] 같은 배경이 연달아 나오지 않음. 노랑은 한 곳
- [ ] 반전(실패 데이터) 바로 뒤에 해결이 이어짐. 출처 각주를 약 3초 읽을 수 있음
- [ ] 숫자·단위 줄바꿈 없음. 글자 최소 크기 지킴(각주 26px 이상)
- [ ] 사진이 흐릿하지 않음(확대 한도 지킴). 사진마다 “공급처 제공”
- [ ] 주석이 가리키는 위치가 정확함
- [ ] `check_copy.py` 효과 표현 0건. 숫자 대조 완료
- [ ] 완성 mp4: 해상도·프레임 수·길이·소리 있음, 소리 크기 -16 LUFS 근처, 클리핑 없음
- [ ] 전환음·효과음이 거슬리지 않음(사용자 청취 확인)

## 8. 게시 전에

| 항목 | 규칙 |
|---|---|
| 검수 띠 | 시안에는 파란 띠를 둔다(“검수용 시안 · … · 판매 확정 전”). 승인 후 `--clean`으로 다시 렌더 |
| 공급처 이미지 가공 | 사용 허용 범위가 “상세설명 이미지 사용”뿐이면 영상 가공 허용을 공급사에 확인 |
| 판매 확정 | 후보용 상품은 게시하지 않음. 공급사 직판가·손익 먼저 |
| 큰 숫자 | 원문 대조 없이 요약 기준으로 센 후기 수치는 대조 후 게시 |
| 등록 규격 | 네이버 스마트스토어 등 올릴 곳의 영상 비율·용량·길이를 확인(현관문 영상 때는 미확인) |
| 공유 문구 | 1~3문장, 효과·최상급 없이 영상 문구에서 가져옴. 계획 문서에 둠 |

## 부록 A. 파일 구조

```text
콘텐츠/홍보영상/
├── README.md
├── 홍보영상_제작_가이드.md     ← 이 문서
├── 홍보영상_제작_레슨런.md
├── 홍보영상_결정기록.md
├── 홍보영상_인계서.md
├── 영상_템플릿/              ← 복사해서 시작(직접 고치지 않음)
└── 상품별/<상품명>/
    ├── 홍보영상_계획.md       ← 구성표·문구 근거·게시 전 확인(핵심)
    ├── 홍보영상_검수용_30초.mp4 ← 완성본(핵심)
    └── 소스/                  ← 영상.html · timing.py · render.py · audio.py · assets/ · 썸네일.jpg(기타)
```

| 파일 | 역할 |
|---|---|
| `timing.py` | 장면 시작 시각과 소리가 붙는 순간(상대 초). 화면과 소리가 같이 읽는 단일 출처 |
| `영상.html` | 8장면의 마크업·스타일·움직임. 맨 아래 스크립트가 `tw(요소, 시작, 길이, 시작값, 끝값, 이징)`로 움직임을 등록하고 `renderAt(t)`가 시각 t의 화면을 만듦 |
| `render.py` | `stills`(확인용 정지 화면) · `video`(프레임→mp4). `--clean`은 검수 띠 숨김 |
| `audio.py` | 음악·효과음 합성, 스테레오 wav 출력 |

## 부록 B. 자주 나는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| 스티커 기울기가 사라짐 | 움직임 코드가 `transform`을 통째로 덮어씀 | 움직임 시작값·끝값에 `r: -2.5`처럼 기울기도 넣음 |
| 어두운 배경 형광펜이 글자를 가림 | 닦는 효과(clip)가 글자까지 자름 | 노란 상자+검은 글자로 만들고 `cr`(오른쪽 잘림)로 닦음 |
| 제목 글꼴이 기본 서체로 찍힘 | 웹폰트가 늦게 로드 | `render.py`가 `document.fonts.load` + `fonts.ready`를 기다림. 실패하면 중단 |
| 사진이 안 뜸 | 상대 경로 | `assets/` 아래에 두고 `src="assets/..."`로 참조 |
| 셸에서 변수에 경로를 담은 긴 `&&` 명령이 출력 없이 실패 | 원인 미확인 | 변수 대신 절대경로를 풀어 쓰고, 단계별로 나눠 실행 |
| 스펙 띠가 숫자 없이 잠깐 비어 보임(0.1초) | 띠가 숫자 칸보다 먼저 나타남 | 띠를 첫 숫자 칸과 같은 시각에 등장시킴(현관문 영상에는 남아 있음) |
