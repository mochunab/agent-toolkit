# 홍보영상 템플릿

> 공개본 안내: 이 스킬에서는 템플릿이 `assets/template/`에 있고 `scripts/new_product.py video <상품명>`이 복사와 이전 상품 흔적 검사를 대신한다. 아래 명령은 손으로 할 때의 예시이며 `영상_템플릿`은 `assets/template`으로 읽는다. 템플릿의 사진 5장은 자리표시 이미지이며 내용은 현관문 고무패킹 영상 그대로다.

> 용도: 새 상품 영상을 시작할 때 복사해서 쓰는 틀. **현관문 고무패킹 30초 영상의 완성 소스 그대로**라 복사 직후 바로 렌더되고, 거기서 상품에 맞게 바꾼다.
> 원칙: 이 폴더는 직접 고치지 않고 **복사해서** 씀. 템플릿을 고치면 이미 만든 상품 영상은 바뀌지 않음. 공통 도구를 개선하면 이 폴더에도 같은 수정을 반영하고 [결정 기록](decision-log-template.md)에 적는다.
> 자매 문서: [제작 가이드](video-guide.md) · [레슨런](lessons.md)

## 1. 무엇이 들어 있나

| 파일 | 역할 | 바꾸는 경우 |
|---|---|---|
| `영상.html` | 8장면(첫 화면·자가진단·반전·확인 3개·설치·마무리)의 마크업·스타일·움직임 | **상품마다 문구·사진·위치·장면 수를 교체** |
| `timing.py` | 장면 시작 시각, 소리가 붙는 순간(상대 초). 화면과 소리가 같이 읽음 | 장면 길이·효과음 시점을 바꿀 때(합계 30초, 0.5초 격자) |
| `audio.py` | 음악·효과음 합성(A마이너, 120BPM), 스테레오 wav | 장면 구성이 바뀌어 소리 이벤트가 달라질 때. **전환음 값(gain 0.10)은 키우지 않음** |
| `render.py` | `stills`(정지 화면) · `video`(mp4) · `--clean`(검수 띠 숨김) | 고치지 않음 |
| `assets/` | 현관문 사진 5장(예시) | **상품 사진으로 교체** |

## 2. 새 상품 시작하기

전제: 상세페이지 시안(v2 수준)과 증거 단계가 있고, [제작 가이드 2장](video-guide.md#2-무엇을-말할까--문구-규칙)의 문구 규칙을 읽음. Python3·Playwright·Chrome·ffmpeg·numpy 필요.

경로에 띄어쓰기가 있을 수 있으므로 모든 경로를 따옴표로 감싸고, `cd` 하지 말고 절대경로로 실행한다.

```bash
# 1. 복사 (<홍보영상>은 …/위탁/콘텐츠/홍보영상 절대경로, <상품명> 바꿔서)
mkdir -p "<홍보영상>/상품별/<상품명>"
cp -R "<홍보영상>/영상_템플릿" "<홍보영상>/상품별/<상품명>/소스"
rm "<홍보영상>/상품별/<상품명>/소스/README.md"     # 템플릿 안내는 상품 소스에 두지 않음

# 2. 사진 교체: 소스/assets/ 의 현관문 사진을 지우고 상품의 상세페이지_디자인/이미지/ 사진을 복사

# 3. 정지 화면 확인 (임시 폴더에 출력)
python3 "<소스>/render.py" stills 3.4,6.9,13.9 "<임시폴더>/stills"
```

복사한 뒤 **현관문 문구·사진이 남지 않았는지** `영상.html`을 검색해 확인한다(`현관문`·`패킹`·`6.3`·`2.1m`·`18`·`32`·`58`). 템플릿은 현관문 영상 그대로라 놓치면 다른 상품 영상에 현관문 내용이 들어간다.

## 3. 현관문 예시에서 상품별로 바꿀 곳

| 바꿀 것 | 위치 |
|---|---|
| 제목·문구·사진 파일명 | `영상.html`의 각 `<section class="scene" id="sA…sF">` |
| 스펙 띠 숫자(6.3m·2.1m × 3줄·18 × 14mm) | A·F 장면의 `.specbar` |
| 후기 말풍선 4개·32/58건·출처 각주 | C 장면. **근거 없으면 장면째 빼고 시간표를 다시 짬** |
| 사진 위 주석 좌표(점선 원·지시선·라벨) | B·D1의 `svg.over` — 사진 격자로 좌표를 읽고 수정 |
| 배치 그림(문 세 변 막대) | D3의 `svg` |
| 장면 수·길이 | `timing.py`의 `SCENES`·`REL`, `영상.html` 맨 아래 스크립트의 장면별 블록 |
| 검수 띠 문구 | `#review` |

- 장면 수를 바꾸면 `영상.html` 맨 아래 스크립트의 장면 목록(`['B','C','D1',…]`), `timing.py`, `audio.py`의 이벤트를 **같이** 고친다. 화면만 고치면 소리가 어긋난다.
- `render.py`의 `POSTER_T = 3.4`는 첫 화면이 자리 잡는 시각이다(0번 프레임·썸네일). A 장면 길이를 바꾸면 같이 고친다.
- 글꼴을 CDN에서 받으므로 인터넷이 필요하다.
- 장면 합계는 `timing.END`(30초). 0.5초 격자(120BPM)를 지켜야 효과음이 박자에 맞는다.
- 상품 사진이 아닌 현관문 전용 도식(문 막대 그림, O/X 두 칸)은 상품에 맞는 단순한 도형으로 새로 그리거나 장면을 뺀다.
