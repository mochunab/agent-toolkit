# 홍보영상 인계서 · 새 영상 시작 양식

> 용도: 새 상품 영상을 시작할 때 AI에게 줄 요청 양식과 시작 순서. 작업을 마칠 때마다 아래 ‘현재 상태’ 표를 갱신해 다음 사람(또는 다음 세션)에게 넘긴다.
> 자매 문서: [제작 가이드](video-guide.md) · [레슨런](lessons.md) · [결정 기록 양식](decision-log-template.md) · [영상 템플릿](template-guide.md)

## 현재 상태 (작업마다 갱신)

| 항목 | 상태 |
|---|---|
| 만든 영상 | [상품·버전·경로] |
| 사용자 반응 | [들은 말 그대로. 승인하지 않은 항목은 승인으로 적지 않는다] |
| 게시 여부 | [게시 안 함 / 어디에 게시] |

## 사용자에게 확인받을 것

1. 올릴 곳과 규격(9:16이 맞는지) 2. 소리 최종 확인 3. 게시 전 확인 항목(공급처 가공 허용·큰 숫자 원문 대조·판매 확정)

## 새 상품 영상 시작 양식 (복사해서 채움)

상세페이지가 끝난 상품에서 시작한다. 대괄호를 채워 AI에게 준다.

```text
상품: [상품명 · 상세페이지_디자인 폴더 위치]
상세페이지 상태: [v2 수준 시안 완료 / 증거 단계 N / 확인 필요 표시 남은 곳]
영상 길이·규격: [기본 30초·9:16, 다르면 적기]
올릴 곳: [스마트스토어 / 릴스 / 쇼츠 / 미정]
쓸 사진: [상세페이지 이미지/ 의 파일 목록과 해상도]
영상에 꼭 넣을 구매 망설임 1~3개: [상세페이지 확인 섹션에서]
뺄 것(운영 약속·미확정): [예: 상담, 반품, 가격]
검수 띠: [시안은 있음 / 게시용은 없음]

홍보영상_제작_가이드.md와 레슨런 1장 원칙을 읽고 시작해줘.
상세페이지 v2 문구를 줄여 장면별 문구·근거 표를 먼저 보여줘(새 주장·숫자 금지).
장면 시간표(0.5초 격자, 합 30초)와 읽는 시간(단어당 0.3초)을 확인한 뒤 화면을 만들어줘.
전환음은 gain 0.10 이하로 시작하고, 소리는 내가 직접 듣고 확인할게.
장면 끝 화면과 전환 중간 화면을 정지 화면으로 전부 보여주고, 문구 검사·숫자 대조 결과를 같이 줘.
```

## 시작 순서 요약 (자세한 건 [가이드 6장](video-guide.md#6-어떻게-만드나--html에서-mp4까지))

1. 가이드 → 레슨런 1장 → 이 인계서 읽기
2. [영상 템플릿](template-guide.md)을 `상품별/<상품명>/소스/`로 복사
3. 문구·근거 표 → 시간표 → 화면 → 정지 화면 검수 → 문구 검사 → 소리 → 렌더 → 재확인
4. [계획](../assets/sample/현관문_영상계획예시.md) 형식으로 `홍보영상_계획.md` 작성
5. 결정 기록에 항목 추가, 교훈은 레슨런으로 승격, 이 인계서 1~2장 갱신
