# 홍보영상 작업

상세페이지 시안을 8장면·30초로 압축한 세로 영상. 규칙은 `references/`에 있다. `<스킬>`은 이 SKILL.md가 있는 폴더, `<작업폴더>`는 콘텐츠 작업 폴더(없으면 현재 폴더)다. 문구·증거 규칙은 `detail-page` 스킬의 `references/strategy.md`가 우선한다(두 스킬을 함께 설치한다).

## 1. 게이트 — 영상부터 만들지 않는다

- [ ] 그 상품의 **상세페이지 시안(v2 수준)과 증거 단계가 있다**. 없으면 `detail-page`로 돌아간다(기본 원칙 — 사용자가 다르게 정하면 따른다)
- [ ] 대본 = 그 상품의 상세페이지. **새 카피·새 구성 금지**, 문구는 상세페이지에서 줄여 온다
- [ ] 증거 단계 문구 규칙 그대로: 효과·시연·전후 비교·가격·반품/상담 약속·경쟁사명·AI 생성 이미지 금지
- [ ] 공급처 이미지를 **영상으로 가공**해도 되는지 확인했거나 게시 전 확인 항목에 적었다
- 필요: Python 3 · Playwright · Chrome · ffmpeg · numpy · 인터넷(글꼴 CDN)

## 2. 시작 전 — 실제로 읽는다

1. `references/video-guide.md` → `references/lessons.md` **1장** → `references/handoff-template.md`(시작 양식)
2. 상세페이지 `strategy.md` 3·4·6절, `design-guide.md` 3·4·5장
3. 예시: `assets/sample/현관문_영상계획예시.md`(구성표·문구 근거 형식)

## 3. 진행

폴더 만들기 — 템플릿을 `상품별/<상품명>/소스/`로 복사하고 **템플릿에 남은 현관문 흔적 목록**을 바로 출력한다. 이미 있으면 덮어쓰지 않고 멈춘다.

```bash
python3 "<스킬>/scripts/new_product.py" video "<상품명>" --root "<작업폴더>"
S="<작업폴더>/홍보영상/상품별/<상품명>/소스"
T="<임시폴더>"      # 프레임·정지 화면·중간 wav는 작업 폴더 밖에 둔다
```

| 단계 | 명령·할 일 |
|---|---|
| 사진 교체 | 상세페이지 `이미지/`의 사진을 `소스/assets/`로 복사, 템플릿 사진(자리표시) 삭제 |
| 문구·근거 표 | 장면별 문구를 상세페이지에서 줄여 고르고 `홍보영상_계획.md`(양식 자동 생성)에 **문구별 근거 위치**를 남긴다 |
| 시간표 | `timing.py` 0.5초 격자, 합 30초. 읽는 시간 = 단어당 0.3초(마지막 줄 기준). 모자라면 문장이 아니라 **장면을 줄인다** |
| 화면 | `영상.html` 장면·문구·위치 교체. 장면 수를 바꾸면 `영상.html` 하단 장면 목록·`timing.py`·`audio.py` 이벤트를 **같이** 고친다 |
| 정지 화면 | `python3 "$S/render.py" stills 3.4,6.9,13.9 "$T/stills"` — **장면 끝 화면 + 전환 중간 화면을 전부** 눈으로 확인 |
| 흔적 검사 | `python3 "<스킬>/scripts/check_leftovers.py" "$S/영상.html"` → **0건**. 걸린 값이 새 상품의 정당한 값(예: 규격 18)이면 `--words 현관문,패킹,6.3,2.1m,58`처럼 이전 상품 단어만 남겨 다시 돌린다 |
| 문구 검사 | `python3 "<스킬>/scripts/check_copy.py" "$S/영상.html" --extra 단열,난연,가격,상담` → 효과 표현 0건 |
| 숫자 대조 | 화면의 모든 숫자를 근거 파일과 하나씩 대조 |
| 소리 | `python3 "$S/audio.py" "$T/audio_raw.wav"` → `ffmpeg -i … -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 44100 …` → 레벨 확인. **전환음 gain 0.10 이하로 시작, 키우지 않는다** |
| 렌더 | `python3 "$S/render.py" video "$T/영상.mp4" --audio "$T/audio.wav"` (약 1분, 900프레임) |

시안에는 파란 검수 띠가 있다. 게시용은 승인 후 `--clean`으로 다시 렌더한다.

## 4. 함정

- 경로 공백·`cd … &&` 무출력 실패 → 따옴표 + `cd` 없이 절대경로
- 템플릿은 **현관문 영상 그대로**다. 흔적 검사를 건너뛰면 다른 상품 영상에 현관문 내용이 들어간다
- 템플릿(`assets/template/`)은 직접 고치지 않는다. 공통 도구를 개선했으면 템플릿에도 같은 수정을 반영한다
- **AI는 소리를 들을 수 없다.** 시안을 전달할 때 반드시 “소리는 직접 들어 확인해 달라”고 말하고, 측정값(LUFS·피크·장면별 RMS)만 검증으로 보고한다
- 올릴 곳(스마트스토어·릴스·쇼츠)과 규격(9:16)은 승인받은 적이 없다 — 게시 직전에 확인한다. 앱이 가리는 위·아래 안전 영역도 그때 확인한다

## 5. 끝내기 전 — 빠뜨리면 미완료

1. 결정 기록(`references/decision-log-template.md` 양식)에 결정·과정·실수 추가
2. 다음에도 적용될 교훈은 레슨런으로 승격, 인계서(`handoff-template.md`)의 현재 상태·사용자 반응·미결 사항 갱신
3. 게시 전 확인 항목(공급처 가공 허용·판매 확정·큰 숫자 원문 대조·등록 규격)을 계획 문서에 남긴다
4. 핵심/기타 분리 — 완성 mp4·`홍보영상_계획.md`는 핵심, `소스/`·썸네일은 기타
