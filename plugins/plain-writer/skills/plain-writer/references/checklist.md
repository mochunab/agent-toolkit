# 퇴고 점검표

draft: 쓴 뒤 스스로 점검한다. "아니오"가 나오면 고치고 다시 본다.
polish: 원문을 진단한다. "아니오" 항목이 '바꾼 점' 표의 이유가 된다.

태그와 `rules.md` 절의 대응:
[받는 사람]=1절 · [문장]=2절 · [용어]=3절 · [화법]=4절 · [수식어]=5절 · [구조]=6절 · [매체]=`channels.md`

## 받는 사람 (가장 먼저)

- [ ] 누가 읽고, 무엇을 물었고, 읽고 무엇을 하는지 정해졌는가? [받는 사람]
- [ ] 분량 안인가? (답 3줄 · 부탁·공유 5줄 · 메시지 10줄/600자) [받는 사람]
- [ ] 줄인 뒤에도 판단을 바꾸는 조건·금액·날짜·미확정이 남아 있는가? [받는 사람]
- [ ] 받는 사람에게 맞는 정보 수준인가? [받는 사람]

## 첫인상 (읽기 전 5초)

- [ ] 첫 두 문장만 읽어도 결론과 할 일이 보이는가? [구조]
- [ ] 제목·첫 줄이 내용을 요약하는가? [구조]
- [ ] 훑어만 봐도 요지가 잡히는가? (소제목·불릿) [구조]
- [ ] 불릿이 3~7개, 2단계 이내인가? [구조]
- [ ] 부탁이면 누가·무엇을·언제까지가 따로 눈에 띄는가? [구조]

## 문장

- [ ] 60자를 넘는 문장이 없는가? [문장]
- [ ] 한 문장에 사실이 하나씩인가? [문장]
- [ ] 모든 문장에 행위자가 있는가? "진행될 예정입니다" 같은 문장이 없는가? [문장]
- [ ] 번역투("~에 의해", "~을 가지고 있다", "~됨에 따라")가 없는가? [문장]
- [ ] 말투가 통일되어 있는가? [문장]
- [ ] `~라고 보시면 됩니다` 같은 흐린 말이 없는가? [화법]

## 용어

- [ ] 같은 대상을 다른 단어로 부른 곳이 없는가? [용어]
- [ ] "문제", "관련 내용" 같은 일반어가 구체어로 바뀌었는가? [용어]
- [ ] 받는 사람이 모를 약어·전문용어에 풀이가 붙었는가? [용어]
- [ ] 추측과 사실이 나뉘어 있는가? [용어]
- [ ] 날짜·금액 표기가 통일되어 있는가? 상대 날짜가 남아 있지 않은가? [용어]

## 수식어

- [ ] "곧", "일부", "많이" 같은 모호한 말이 숫자·날짜로 바뀌었는가? [수식어]
- [ ] 지워도 뜻이 같은 부사(매우, 정말, 상당히)가 없는가? [수식어]
- [ ] 완충 표현(좀, 일단, 사실상)과 관용구(다름이 아니라)가 없는가? [수식어]
- [ ] 이중 완곡("혹시 가능하시다면 한번…")이 직접 부탁으로 바뀌었는가? [수식어]
