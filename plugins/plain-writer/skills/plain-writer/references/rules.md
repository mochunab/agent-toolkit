# 쉬운 글쓰기 규칙

사람이 읽고 판단하는 한국어 글에 쓴다. 업무 메시지·이메일·보고서, 모임 공지, 문의·민원, 가족 단톡까지 같다.
코드 주석·커밋 메시지·영어 글·소설·광고 카피는 대상이 아니다.

판정 기준은 하나다. **받는 사람이 한 번 읽고 이해하고, 무엇을 해야 하는지 아는가.**

## 1. 쓰기 전에 셋을 정하고, 담는 양을 줄인다

1. **누가 읽나** — 상사·동료·고객·가족·모임 회원·관공서·처음 보는 사람
2. **무엇을 물었나, 꼭 알아야 하나** — 질문이 있으면 그 질문이 기준이다
3. **읽고 무엇을 하나** — 결정 / 확인 / 행동 / 참고

- **빼는 것**: 상대가 이미 아는 배경, 내가 고생한 과정, 묻지 않은 세부, 같은 말 반복
- **남기는 것**: 판단을 바꾸는 조건·금액·날짜·미확정 사항, 묻지 않았어도 꼭 알아야 할 위험
- 문장을 깎아서는 안 줄어든다. **담는 내용을 줄인다.** 조건을 떨어뜨리면 문장이 거짓이 된다.

| 용건 | 분량 |
|---|---|
| 질문에 대한 답 | 3줄 이내, 첫 줄이 답 |
| 확인·부탁 | 5줄 이내 — 무엇을, 누가, 언제까지 |
| 소식·근황 공유 | 5줄 이내, 자세한 건 링크·첨부 |
| 메신저 한 메시지 | 10줄·600자를 넘으면 나누거나 링크로 |
| 한 메시지의 용건 | 1건 권장, 3건이 넘으면 나눈다 |
| 꼭 길어야 할 때 | 맨 위 3줄 요약 + 아래 상세 |

상대가 길게 보내도 길이를 맞추지 않는다.

## 2. 문장

- 한 문장에 사실 하나. `~고/~며/~지만/~는데/~해서`로 두 사실을 잇지 않는다.
- 40자 안팎으로 쓰고, **60자가 넘으면 나눈다**. 한 문장에 숫자는 1개까지.
- 행위자를 주어로: `수리가 진행될 예정입니다` → `관리사무소가 5/20(화)에 수리합니다`
- 늘어진 끝맺음을 줄인다: `~할 수 있을 것으로 생각됩니다` → `~합니다`
- 명사화를 되돌린다: `확인을 진행하다` → `확인하다`
- 번역투를 뺀다: `~에 의해`, `~을 가지고 있다`, `~됨에 따라`, `~에 있어서`
- 한 글 안에서 말투를 통일한다 (`~합니다` / `~해요` / `~함`).

## 3. 용어

- 일반어 대신 구체어: `문제가 있어서` → `보일러가 안 켜져서`
- 한 대상은 한 단어로 부른다 (회원/멤버/참가자 중 하나).
- 상대가 쓰는 말을 쓴다. 내가 지어낸 이름은 쓰지 않는다.
- 약어·전문용어는 첫 등장에 쉬운 말을 붙인다: `관리비 장기수선충당금(큰 수리용 적립금)`
- 사실과 추측을 나눈다. 모르면 `확인 중` 또는 `○○에게 확인 필요`라고 쓴다.
- 표기를 고정한다: `2026-05-20`, `5/20(화)`, `12,000원`. 내일·다음 주 같은 상대 날짜는 날짜+요일로.

## 4. 확정된 말을 흐리지 않는다

| 상태 | 좋음 | 나쁨 |
|---|---|---|
| 확정 | `5/20 출발합니다` | `5/20 출발한다고 보시면 됩니다` |
| 미확정 | `아직 정해지지 않았습니다. 5/20이 유력합니다` | `5/20쯤으로 보시면 됩니다` |
| 모름 | `받은 자료로는 알 수 없습니다` | `없다고 생각하시면 됩니다` |

`~라고 보시면 됩니다`, `~로 이해하시면 됩니다` 같은 말은 확정도 미확정도 아닌 말이다. 셋 중 하나로 고친다.

## 5. 모호한 말과 군더더기

| 나쁨 | 좋음 |
|---|---|
| `일부`·`여러`·`많이` | 실제 수 (`3명`). 안 셌으면 안 셌다고 쓴다 |
| `곧`·`빠른 시일 내`·`최대한 빨리` | 날짜 (`5/20`). 모르면 `날짜 미정` |
| `담당자분`·`관련 부서` | 이름·부서명 |
| `적절히`·`필요하면`·`가능하면` | 조건문 (`비가 오면 실내로 옮깁니다`) |
| `등`·`기타` | 전부 적거나 `그 밖에는 확인 못 함` |
| `대폭`·`훨씬`·`효율적인` | 수치 (`월 3만 원 → 2만 원`) |

모호한 말은 대개 "확인하지 않았다"는 뜻이다. 다듬지 말고 확인하거나 묻는다.
지워도 뜻이 같은 말은 지운다: `매우·정말·상당히·좀·일단·사실상`, `다름이 아니라·참고로 말씀드리면`, `혹시 가능하시다면 한번…`

## 6. 구조

- **결론 먼저.** 첫 1~2문장에 무엇을 / 왜 / 상대가 할 일. 질문에는 첫 줄에 답을 쓴다.
- 첫 줄을 예고(`정리해서 말씀드리면`)·감사·상대 말 되풀이로 시작하지 않는다.
- 제목이 내용을 요약한다: `안내` ❌ → `6/1(일) 정기모임 장소 변경: 강남역 → 신촌역` ✅
- 한 덩어리에 한 주제. 불릿은 3~7개, 2단계까지. 비교는 표로.
- 부탁은 따로 떼어 분명히: 누가 + 무엇을 + 언제까지.
- 여러 사람에게 쓰면 사람별로 나눠 각자 할 일만 적는다.
- 근거·상세는 링크·첨부로 넘긴다. 출처는 맨 아래에 모은다.

## 7. 내보내기 전 점검

1. 1절의 셋에 답했나. 첫 줄이 답인가. 분량 안인가. 줄인 뒤에도 조건·미확정이 살아 있나.
2. 60자 넘는 문장을 나눴나.
3. 처음 나온 약어·지어낸 이름에 풀이가 붙었나.
4. 상대가 할 일이 3건을 넘으면 메시지를 나눴나.
5. 애매한 문장 하나를 더 뺀다.
6. 답장이면 앞 대화를 끝까지 읽었나. 이미 나온 답을 다시 쓰지 않는다.
