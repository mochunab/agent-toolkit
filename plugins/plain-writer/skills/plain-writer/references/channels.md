# 매체별 형식

받는 사람·매체를 정한 뒤 해당 절만 적용한다. 공통 규칙은 `rules.md`가 정본이다.

## 메신저·문자 (업무 채팅, 카톡, 단톡방, 문자)

- 첫 줄에 결론이나 답. 인사·예고로 시작하지 않는다 (친한 사이의 짧은 인사 한마디는 괜찮다).
- 답 3줄, 부탁·소식 5줄, 최대 10줄·600자. 넘치면 링크·첨부·다음 메시지로 나눈다.
- 제목(`#`)·표는 쓰지 않는다. 메신저에서 깨진다. 굵게는 꼭 필요한 한 곳만.
- 부탁이면 한 줄에 대상 + 할 일 + 기한: `5/18(일)까지 참석 여부 댓글로 남겨 주세요.`
- 단순 공유면 답장이 필요 없다고 밝힌다.

```
6/1(일) 정기모임 장소가 신촌역 2번 출구 ○○카페로 바뀌었습니다.
• 시간: 오후 2시 그대로
• 회비: 1만 원 (현장 결제)
5/29(목)까지 참석 여부를 댓글로 남겨 주세요.
```

## 이메일

- 제목에 성격을 붙인다: `[요청]`, `[공유]`, `[문의]`, `[결정 필요]` + 내용 요약.
- 첫 문단에 결론과 요청. 상세는 아래에.
- 인사는 한 줄. 사과·안부로 늘리지 않는다.
- 요청이면 끝에 대상·할 일·기한을 따로 적는다.
- 첨부가 있으면 본문에 무엇을 첨부했는지 한 줄로 적는다.

```
제목: [문의] 5/10 주문(주문번호 12345) 환불 진행 상황

5/10에 주문한 의자를 5/12에 반품했습니다. 아직 환불이 되지 않아 문의드립니다.
• 반품 송장: 1234-5678
• 환불 금액: 89,000원
5/23(금)까지 환불 예정일을 회신해 주세요.
```

## 문의·민원·항의 (고객센터, 관리사무소, 집주인, 관공서)

- 첫 줄에 무엇이 문제이고 무엇을 원하는지 쓴다.
- 사실을 시간 순으로 짧게: 언제, 무엇이, 어떻게 됐나. 감정 표현은 한 문장까지.
- 근거(사진·영수증·번호)는 목록으로 붙인다.
- 원하는 조치와 기한을 분명히 쓴다: `5/25(일)까지 수리 일정을 알려 주세요.`

## 공지·안내문 (모임, 아파트, 동호회, 학급)

- 제목이 내용을 요약한다: 날짜·무엇·바뀐 점.
- 핵심 4가지를 맨 위에: 언제 / 어디서 / 무엇을 / 내가 할 일.
- 바뀐 공지면 무엇이 바뀌었는지 `이전 → 변경`으로 보인다.
- 문의처를 맨 아래 한 줄로.

## 문서·보고서

- 순서: 요약 → 본문 → 부록. 요약은 3~5문장이고 결론과 요청을 담는다.
- 3쪽이 넘으면 목차를 넣는다.
- 제목·소제목은 내용을 요약한다 (`검토 결과` 금지).
- 표는 열 5개 이내. 대안 비교는 표로.
- 결정이 필요한 문서는 요약에 **추천안**과 **결정 기한**을 넣는다.

```
# 이사 업체 비교: A사 추천

## 요약
(결론 1문장) (근거 1~2문장) (요청: 무엇을 언제까지)

## 비교
| 업체 | 견적 | 날짜 | 보험 |
## 추천과 이유
## 할 일
```
