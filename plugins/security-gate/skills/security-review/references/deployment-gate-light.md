# 배포 보안 게이트 — 경량 프로파일

개인·사이드 프로젝트용. **로컬에서 돌릴 수 있는 검사 + 배포 후 운영 스모크**로 끝낸다. 격리 환경·인증 fixture·CI 강제 차단은 요구하지 않는다. 중량 기준은 [deployment-gate.md](deployment-gate.md).

## 적용 조건 (모두 충족해야 경량)

- 프로젝트 `CLAUDE.md`/`AGENTS.md`에 `보안 프로파일: 중량`이 없다. **명시가 없으면 경량**이다(`보안 프로파일: 중량`이 명시된 프로젝트만 중량).
- 소유자 1인, 결제·정산 없음, 제3자 개인정보(이름·연락처·위치 등) 대량 저장 없음, 팀원·외부 사용자 권한 모델 없음.
- 위 조건이 하나라도 깨지면(결제 도입, 타인 가입자 데이터 저장, 팀 공유 등) 즉시 중량으로 올린다.

## 필수 검사 (실제 명령·종료 상태로 판정)

| 항목 | 기준 |
|---|---|
| 시크릿 | gitleaks로 전체 Git 이력 + 현재 파일. 발견 0건. 오탐은 경로·값 단위 allowlist로만. `.env`·키 추적 여부, service-role 키의 클라이언트·번들 노출 확인 |
| 의존성 | `npm audit --audit-level=high` 0건. 런타임 패키지 HIGH/CRITICAL은 예외 없음. 빌드·개발 전용 major-only만 [예외 절차](deployment-gate.md#의존성-예외) 허용 |
| SAST | semgrep ERROR 0건(규칙·버전 기록). WARNING은 목록과 수용 사유 기록 |
| 타입·테스트·린트 | 프로젝트가 정한 명령(tsc·단위 테스트·lint) 통과 |
| 쓰기·비용 API | 서버에서 인증하는지 **코드로 전수 확인**(POST/PUT/PATCH/DELETE 라우트 목록 대조). 비로그인으로 호출하면 안 되는 것은 가드 선행 + 회귀 테스트 |
| 접근제어 | 비공개 데이터(예: master 전용 노트·포트폴리오)는 서버 렌더·API·정적 자산 경로에서 막히는지 코드 확인 |
| RLS | 운영 DB는 **읽기 전용**으로 `pg_policies`·`relrowsecurity` 조회해 판정. 공개 읽기 허용, 무단 쓰기 거부. 마이그레이션 적용은 별도 승인 |
| 입력·에러 | 파라미터 바인딩, HTML 정화, `error.message` 사용자 노출 없음 |

## 배포 후 운영 스모크 (읽기 전용·비파괴)

1. HTTPS·인증서·HSTS·CSP·nosniff·frame 보호 헤더를 운영 URL에서 확인.
2. **비로그인**으로 비공개 경로(master 전용 페이지·자산·삭제/비용 API)가 404/401인지 확인. 쓰기 호출은 인증 없이 거부되는 것만 확인하고, 운영 키로 성공 경로를 실행하지 않는다.
3. master 로그인으로 핵심 화면이 열리는지 확인.
4. 이상 시 이전 배포로 롤백(`vercel` rollback 또는 이전 deployment promote). 롤백 방법을 배포 전에 한 줄로 적어 둔다.

## 경량에서 생략하는 것 (미검증이 아니라 "경량 생략")

격리 staging/preview 환경, 실제 인증 fixture HTTP 테스트, CI 필수 체크·branch protection, Vercel 독립 배포 경로 차단, 배포 스위치, 동일 SHA 플랫폼 빌드 증거. 결과표에는 `경량 생략`으로 적고 Pass로 표기하지 않는다.

## 판정·보고

- 필수 검사 Block/미검증이면 중단. 도구 미설치·실행 실패를 Pass로 바꾸지 않는다.
- 판정 문구: `배포 가능(경량)` / `중단`. 보고에 프로파일, SHA, 검사 시각, 생략 항목, 롤백 방법을 포함한다.
- 코드·의존성·정책이 바뀌면 영향받는 검사를 다시 실행한다. 배포 대상 SHA와 검사 SHA를 일치시킨다.
